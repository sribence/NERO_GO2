# Haladó érzékelés és taktika — későbbi TODO (2026-10-02)

Forrás: operátori ötletlista. **Fejlesztési út: ROS 2 + lokális gép + Isaac Sim/Lab (tanítás, teszt) → csak utána valódi robot.** Státusz: **nincs elkezdve**. Előfeltétel: OmniVision 360 (doc 21–23) élesben fut.
