# AI Context - NERO_GO2 System Integrator Repository

## System Overview
Ez a **NERO_GO2** központi integrátor tárolója. A tároló feladata a Unitree Go2 robot teljes szoftveres rendszerének integrációja, hálózati beállításai, rendszerbiztonsági dokumentációja és globális Docker-orkesztrációja.

## Moduláris Submodule Architektúra
A fejlesztési feladatok elkülönítéséhez a rendszer 3 fő almodulból áll az `src/` mappában:

1. **`src/go2-hardware-bridge/`** (`go2-hardware-bridge` repó):
   - Szenzor- és hardver-illesztők (WebRTC, Hesai LiDAR, RealSense, Wi-Fi driver).
2. **`src/go2-gui-visualization/`** (`go2-gui-visualization` repó):
   - Webes felületek, 3D Digital Twin, HUD, integrált `go2-console` és felület-tesztelő mock robot.
3. **`src/go2-brain-logic/`** (`go2-brain-logic` repó):
   - Magas szintű autonómia, LiDAR SLAM, Nav2 útvonaltervezés, Mission Control backend.

## AI Fejlesztési Irányelvek
Amikor egy specifikus feladaton dolgozol (pl. kamerahiba, UI dizájn vagy SLAM navigáció), **mindig csak a megfelelő almodul mappáját nyisd meg** (`src/go2-hardware-bridge`, `src/go2-gui-visualization` vagy `src/go2-brain-logic`), hogy a kontextusablak tiszta és fókuszált maradjon. Minden almodul saját `.ai-context.md` leírással és futtatható `mock_*.py` tesztscripttel rendelkezik.
